# Сборщик накладных Kaspi (веб-версия, без сервера)

Статический сайт: ZIP или PDF с накладными обрабатываются **прямо в браузере**. Файлы никуда не загружаются, бэкенда нет. Все библиотеки лежат в `vendor/` (pdf.js 3.11 legacy, pdf-lib 1.17, JSZip 3.10), внешних CDN нет. CSP разрешает запросы только к своему домену.

Что умеет:
- выбор пункта приема с количеством накладных, а также вариант «Все»; выбор запоминается;
- удаляет повторы за день (история в localStorage этого браузера, кнопка «Сбросить день»);
- сортирует по товару;
- форматы печати: A4, A4 по 2/4/6/8/16 на листе, термоэтикетки 100×150 и 75×120 с автообрезкой полей;
- «Пересобрать в выбранном формате» без повторной загрузки (IndexedDB).

Поддерживаются Chrome, Edge, Firefox и Safari 15+ (macOS 12).

## Запуск локально
`python3 -m http.server 8000` в этой папке, затем откройте http://localhost:8000. Через file:// не работает из-за ограничений браузера на worker.

## Netlify (перетаскиванием)
1. Откройте https://app.netlify.com/drop и войдите в аккаунт.
2. Перетащите туда папку `kaspi_web` целиком (или распакованный архив).
3. Сайт сразу будет доступен по адресу вида `https://<имя>.netlify.app`. Имя можно поменять в Site settings → Change site name.
Заголовки безопасности и кэширования настраиваются в `netlify.toml`.

## GitHub Pages
1. Создайте репозиторий и загрузите в его корень содержимое этой папки (index.html, app.js, style.css, vendor/ …).
2. Откройте Settings → Pages → Source: «Deploy from a branch», выберите ветку `main` и папку `/ (root)`, нажмите Save.
3. Через 1–2 минуты сайт появится по адресу `https://<user>.github.io/<repo>/`. Пути в приложении относительные, поэтому всё работает и в подпапке.

## Приватность
Накладные содержат персональные данные покупателей. Они остаются в памяти и хранилище браузера на вашем компьютере. В историю пишутся только хэши, номера заказов, товары и пункты, PDF туда не сохраняются. Последняя партия хранится в IndexedDB для пересборки и перезаписывается при следующей загрузке. Очистка данных сайта в браузере удаляет всё.
